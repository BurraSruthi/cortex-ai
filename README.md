## 📌 About the Project

Cortex AI is a personal money-balancing and financial decision-support system designed to help users manage their finances more effectively.

The application provides a platform where users can manage their budgets, track financial goals, explore personalized recommendations, and organize financial plans.

It combines a user-friendly frontend with a Python-based backend and a MySQL database to provide a structured financial management experience.

## ✨ Key Features

- **User Authentication:** Secure user registration and login.
- **Budget Management:** Manage and organize personal budgets.
- **Financial Goals:** Create and track financial goals.
- **Personalized Recommendations:** Get financial recommendations.
- **Financial Planning:** Organize and manage financial plans.
- **Lifestyle Management:** Support financial decisions based on lifestyle-related information.

## 🏗️ Project Architecture

1. **Frontend:** Provides the user interface and communicates with the backend API.
2. **Backend:** Handles authentication, financial operations, and application logic using FastAPI.
3. **Database:** Stores application data using MySQL hosted on Railway.

## 🚀 Deployment

The application is deployed using:

- **Vercel** – Frontend hosting.
- **Render** – Backend API hosting.
- **Railway** – MySQL database hosting.
